# Cloud-Based Personal Portfolio Website
A responsive personal portfolio website built using HTML and CSS and hosted on Amazon S3 Static Website Hosting.
## Technologies Used
- HTML
- CSS
- Amazon S3
## Features
- About section
- Skills section
- Projects section
- Contact section
- Responsive design
- Hover animations
## Deployment
The website is deployed using Amazon S3 Static Website Hosting.
## Project Purpose
This project was created to learn the basics of cloud storage, static website hosting, web development, and AWS deployment.
